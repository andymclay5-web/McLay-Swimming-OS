# Rebuilt engine ownership index

| Engine | Sole responsibility |
|---|---|
| Session Truth | Natural coaching language -> canonical session structure and distance |
| Session Lifecycle | Draft/create/select/edit/revision/session identity/persistence contract |
| Evidence Retrieval | Read-only athlete/test/result/conversion evidence with provenance |
| Results / Pathway | PBs, standards, gaps, points, progression and pathway facts |
| Targets | T400 aerobic targets, PB race pace, course conversion, loaded race-model segments |
| Adaptation | Athlete-specific prescription derived from canonical group work |
| Attendance | Exact-session Roll truth |
| Board Projection | Compact read-only projection of canonical work + attendance + targets + adaptations |
| Capture Evidence | Permanent session/block/item/athlete evidence addresses and revision history |

No domain engine owns the browser UI, localStorage/IndexedDB, cloud/network transport, or another engine's implementation.
