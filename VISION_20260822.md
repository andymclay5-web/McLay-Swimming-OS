# MSOS poolside interaction vision — 22 Aug 2026

## Product rule
Eyes up first. Voice first. Big Board second. Phone touch only when necessary.

MSOS should know enough about where the coach is that the coach mostly tells it what happened, not where to file it.

## Live context hierarchy
1. Explicit coach / meet anchor
2. Observed MSOS action or saved evidence
3. Estimated session / meet timeline

The timeline is advisory. It never overwrites delivered truth.

## Poolside surfaces
- Coach: earbud + voice + minimal phone touch
- Swimmers: TV Board / personal device
- System: canonical session, current context, evidence, interpretation and reporting

## Voice economics
- Local deterministic operations first: names, current set, rep, PB query, targets, metrics, timestamps, navigation and evidence linking
- Device speech recognition where available
- API/AI only where it adds material value: ambiguity, long transcription, summarisation, cross-session interpretation, richer media analysis

## Timing ownership
- Aerobic work: SELF CLOCK. Athlete owns target/rest/departure; coach spot-checks and coaches movement/intent.
- Race pace / max / test / precision quality: COACH TIME.

## Remote athlete rule
Absence must not create extra programming work. A remote/holiday athlete receives the same canonical session transformed through their own modification/target layer; a separate branch is created only when the coach deliberately prescribes different work.

## Evidence rule
Raw evidence is immutable. Context and later interpretation may be enriched without rewriting what was actually captured.

Evidence object should support:
- swimmer(s)
- session/block/set/rep context
- raw audio/video/photo/text
- transcript
- structured metrics
- author/source
- delivery/audience
- derived interpretation/carry-forward

## Reporting hierarchy
Capture once, roll upward automatically:
session → week → training block → season → swimmer record → coach report.

## Commercial architecture
Core product remains strong without AI. Variable-cost intelligence sits above it as optional paid capability. Product tiers should primarily scale automation, voice, transcription, interpretation, media processing and multi-coach intelligence rather than withholding basic coaching truth.
